## 🔥 Featured Projects

### [SpaceBetweenUs](https://github.com/Kiryuumaru/SpaceBetweenUs)
![Stars](https://img.shields.io/github/stars/Kiryuumaru/SpaceBetweenUs?style=flat)
![Patent](https://img.shields.io/badge/Patent-PH22021050738U1-blue)

A project that detects and calculates human distance using reverse homographic projection. This system uses YOLOv3 to detect humans and applies reverse homographic projection calculations to measure distances between people in real-time.

**Patented Technology:** This project is protected under patent [PH22021050738U1](https://worldwide.espacenet.com/patent/search/family/079867845/publication/PH22021050738U1?q=ph22021050738U1) - "Real-Time Computer Vision System for Physical Distance Monitoring in Public Areas"

The system captures video in real-time from IP or USB cameras, processes each frame through a software application installed on a microcomputer, and triggers alerts when physical distancing violations are detected.

### [CheckMate: Educator's Toolkit](https://www.checkmate.ph/)
![App](https://img.shields.io/badge/App-Live-brightgreen)
![Platform](https://img.shields.io/badge/Platform-Mobile-orange)
![Technology](https://img.shields.io/badge/Technology-OMR-blue)

CheckMate is a mobile solution that focuses on reducing educators' tedious tasks such as the traditional way of checking, manual input of grades, and constant computation through automation.

**Key Features:**
- Custom mathematical Optical Mark Recognition (OMR) for faster mobile phone recognition
- Automated test grading and score calculation
- Simplified grade management system
- Intuitive, hassle-free interface designed for educators

This application makes it easy for educators to conduct and grade tests, significantly reducing administrative workload and increasing their family, social, and personal time.

Visit [checkmate.ph](https://www.checkmate.ph/) to learn more about this project and its features.

### [NukeBuildHelpers](https://github.com/Kiryuumaru/NukeBuildHelpers)
![Stars](https://img.shields.io/github/stars/Kiryuumaru/NukeBuildHelpers?style=flat)
![CI/CD](https://img.shields.io/badge/CI%2FCD-Supported-success)
![SemVer](https://img.shields.io/badge/SemVer_2-Compliant-blue)

A C# project build automation tool built on top of NukeBuild. This framework enhances CI/CD pipelines with advanced features for complex development workflows.

**Key Features:**
- Support for both GitHub Actions and Azure Pipelines
- Comprehensive release management across multiple projects and environments within a single repository
- Advanced multi-environment branch management with separated versioning following SemVer 2
- Streamlined deployment process with faster version management
- Simplified workflow for managing complex project dependencies

This tool significantly reduces the overhead of maintaining build scripts and versioning across large projects.
